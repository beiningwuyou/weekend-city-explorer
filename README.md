# 周末城市探索指南 (Weekend City Explorer)

> 基于俞军产品方法论与情境感知的极速周末探索决策 Web 应用。专为大学生与青年群体打造的城市微度假、周边游探索工具。

---

## 🌟 在线体验链接

👉 **[点击立即访问体验](https://beiningwuyou.github.io/weekend-city-explorer/)**

*(页面采用移动端优先设计，手机或微信打开体验最佳)*

---

## 📱 核心功能特性

1. **情境化极速推荐**：
   - 支持按城市/高校园区（如广州大学城、五山高校圈等）快速圈定半径。
   - 提供「懒人说走就走」、「文艺治愈系」、「特种兵徒步」、「学生党高性价」等多种场景模式。
2. **打卡盖章与交互激励**：
   - 沉浸式数字打卡盖章动效。
   - 探索路线规划与时间轴行程一览。
3. **极简纯前端架构**：
   - 纯 HTML5 + Tailwind CSS + Lucide Icons 构建。
   - 零服务端依赖，支持 GitHub Pages / Vercel 秒级冷启动与离线缓存。

---

## 🛠 本地运行

无需复杂的构建流程，直接在浏览器中打开 `index.html` 即可：

```bash
# 克隆仓库
git clone https://github.com/beiningwuyou/weekend-city-explorer.git
cd weekend-city-explorer

# 使用任意静态服务器启动（或双击 index.html 运行）
npx serve . -p 3000
```
